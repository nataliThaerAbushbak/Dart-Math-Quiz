# Math Quiz Application

## Project Description
This project is a console-based Math Quiz Application developed using Dart. It allows users to answer math questions, receive optional hints, get instant feedback, and see their final grade and time spent.

## Features
- Multiple math questions
- Optional hints
- Answer checking
- Question difficulty detection
- Final grade calculation
- Quiz timer
- Console-based user input

## Technologies Used
- Dart
- Object-Oriented Programming

## Project Structure
- main.dart
- BaseQuestion.dart
- MathQuestion.dart

## OOP Concepts Used
- Inheritance
- Encapsulation
- Method overriding
- Constructors
- Getters
- Static variables
- Enums

## How to Run
1. Install Dart SDK.
2. Open the project folder.
3. Run:

```bash
dart run
```
